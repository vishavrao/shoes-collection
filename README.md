# Shoes Collection — client demo

A responsive static storefront demo built from 24 supplied product photographs with visible branding removed. Includes collection search, filtering, sorting, product detail views, saved items, sample bag, sample account, contact form, FAQs and draft policies.

Saved items, bag selections and sample account name/email stay in the visitor's browser local storage. Authentication, checkout, payments, orders, message delivery and newsletter sign-up are not connected. Add confirmed prices, sizes, stock, business contact details and approved policies before commercial launch.

Open `index.html` locally or publish from a GitHub Pages repository root. No build step is required.
