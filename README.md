# Hide & Sole — The Leather Edit

A responsive, static catalog built from the 24 supplied product photographs. Open `index.html` locally or publish this folder with GitHub Pages (Deploy from a branch, root directory). No build step is required.

The product names describe visible colours and styles. Prices, sizes, materials, stock and seller contact details were not supplied, so this site does not claim them or offer checkout.

Brand names visible in the supplied photography belong to their respective owners.
